## 二、两条托管路线（都免费、都不需要备案）

### 路线 A（推荐）：Cloudflare Pages

**为什么推荐**：带宽不限量；国内访问在海外托管里算相对稳；以后接后端可以直接用同一家的
Workers + D1 + R2（素材搬到 R2 还能省流量、加速）。

1. 打开 https://dash.cloudflare.com/sign-up 注册（邮箱即可，免费）
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**
3. 项目名填 `qilv`（会得到 `qilv.pages.dev` 这样的临时网址）
4. 把 **`栖旅-完整版-日期` 文件夹**整个拖进去（或上传同名 zip）→ **Deploy**
5. 等 1–2 分钟，得到网址，先自己点开看看

### 路线 B：Netlify Drop（最快，纯拖拽）

1. 打开 https://app.netlify.com/drop
2. 把 **`栖旅-完整版-日期` 文件夹**拖进页面
3. 立刻得到一个 `随机名.netlify.app` 网址；注册账号后才能保留并改域名

> 两家的免费额度对我们这个阶段都够用。差别是：Cloudflare 之后接后端更顺，
> Netlify 上手更快。**建议 A**，但如果只是想先看一眼线上效果，B 三十秒就能成。

## 四、上线之后立刻要做的三件事（下一步工作）

1. **接后端**（Supabase 或 Cloudflare Workers+D1）：账号、帖子、回复、点赞、收藏从
   "只在你浏览器里"变成真的共享；登录分级判断搬到服务端。
2. **素材搬 CDN**：91MB 视频放 R2 / Bunny，页面按需加载，国内速度会明显变好。
3. **合规三件套**：用户协议、隐私政策、内容审核（敏感词 + 图片审核）——公开邀请用户之前必须有。

## 五、注意

- 海外托管**不需要备案**，但国内访问速度一般；如果以后要"国内快 + 正规"，需要单位主体
  （企业，部分地区个体工商户可能受理）做备案，UGC 社区还要有内容审核能力，整套 2–6 周。
- 免费套餐有流量上限（Netlify 100GB/月；Cloudflare Pages 带宽不限但请求数有软限制）。
  真有人用了要提前看用量。
- 上线不是终点：**链接发出去之后，第一件事是看有没有人真的发帖**，那才决定后面做什么。
