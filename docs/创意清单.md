# 栖旅 · 「极具创意」的方向清单

2026-09-28 整理。每条都是**能落到这个站上的具体做法**，不是形容词。
标了工作量：🟢 小（半天内）· 🟡 中（1–2 天）· 🔴 大（3 天以上）。

---

## 1. 城市印章（City Seal）🟡

每座城市根据自身数据生成**一枚独特的图形印章**：城市名首字 + 由指数、气候、成本画出的
几道弧线与刻度，像篆刻又像唱片。出现在画廊卡片角落、城市页顶部、分享图上。

**为什么好**：69 座城市从此各有"面孔"，一眼能认出、能记住；而且它是从数据生成的，
数据变了印章也变——既是可视化，又是品牌识别系统。分享出去的图自带印章，传播时就是 logo。

## 2. 到达时间环（不要地图也能看懂距离）🟡

以这座城市为圆心画同心环：**2 小时圈 / 4 小时圈 / 8 小时圈**，把周边城市按高铁或飞行
时长摆进对应的环里。

**为什么好**：你明确说过不要地图。这个方案用"时间"代替"空间"，比地图更贴旅居视角
（关心的是"多久能到"，不是"在哪个方位"），而且比纯列表直观十倍。

## 3. 住多久滑杆 🟡

一根滑杆：**一周 / 一个月 / 三个月 / 半年**。选定后整套信息跟着变——月均花销（含短期溢价）、
带什么、能不能远程办公、医疗够不够、哪几个月来最划算。

**为什么好**：把"旅居"和"旅游"彻底分开，是这个产品最核心的差异点，而 UI 上只要一根滑杆。

## 4. 听一下这座城市 🟢

点一下用 WebAudio **现场合成**一段环境声（风、水、低频的夜市嗡鸣），不依赖任何版权素材；
天黑时声音更沉、白天更亮。

**为什么好**：全网旅居站都没有声音层；成本几乎为零、却能让人瞬间"在场"。

## 5. 季节皮肤 🟡

在城市页点某个月，**整页色调跟着换**（春绿 / 夏蓝 / 秋金 / 冬灰），并显示
"那一个月来，你会看到什么"。

**为什么好**：现有十二个月图表只讲数据，季节皮肤让"选月份"变成有情绪的体验。

## 6. 我的旅居画像（偏好滑杆的延伸）🟢

城市页的偏好滑杆已经能实时重算指数并让画廊重排。再往前一步：**把画像存下来当成身份**——
首页默认按你的画像排、卡片显示"你的指数"、社区里能按画像找同类人。

**为什么好**：这是从"看榜单"到"我的榜单"的跃迁，也是最自然的注册动机。

## 7. 一天的生活脚本 🟢

用城市已有的标签与细节，生成一条**典型一天**的时间带：几点天亮、几点咖啡馆开、
菜市场几点最热闹、夜市几点散。

**为什么好**：数据是冷的，"一天"是热的——能让人立刻想象自己住在那儿。

## 8. 社区的时间胶囊 🟡

按月份检索历史帖子："**去年的这个月，有人在大理**"。没有新帖的城市也能被激活。

**为什么好**：冷启动阶段内容少，这是最省力的内容放大器。

## 9. 数据可信度可视化 🟡

每个数字旁边一个小"证据链"图标，点开显示来源、样本量、更新时间与核实状态
（示例 / 估算 / 待核实 / 实时）。

**为什么好**：你说过数据要真实。把它做成**能点开的证据**，就成了别人抄不走的卖点，
而不是页面底部一句免责声明。

## 10. 画廊的电影模式 🟢

键盘 ← / → 像翻画册一样逐幅看，背景色跟着画幅变，城市名用大字浮现。

**为什么好**：把"画廊"从网格变成一次观看体验，也是最适合截图传播的形态。

## 11. 三问推荐（性格测试式入口）🟢

三个问题：我怕热吗 / 我需要大城市吗 / 我的预算多少 → 给出 3 座城市与理由。

**为什么好**：新访客第一次进来不知道点哪，这是最好的向导；也是转化注册的钩子。

---

## 建议的推进顺序

1. **城市印章** + **三问推荐** —— 一个立品牌、一个拉新，都是小工作量。
2. **到达时间环** —— 补上"位置感"，且绕开了地图。
3. **住多久滑杆** + **季节皮肤** —— 一起做，把"旅居 vs 旅游"这件事讲透。
4. **听一下这座城市** + **一天的生活脚本** —— 情绪层，成本低、记忆点强。
5. **数据可信度可视化** —— 上线前必须做，和真实数据一起上。
6. **社区时间胶囊**、**电影模式** —— 内容与体验的长期增益。
